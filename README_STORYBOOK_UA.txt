AMBER WORLD — STORYBOOK 2D

ЗАПУСК У WINDOWS
1. Повністю розпакуйте ZIP у папку з доступом на запис.
2. Запустіть Start_HEX.vbs. Рушій уже включено до _runtime.
3. Перший запуск імпортує ресурси й може тривати довше.
Якщо Forward+ не запускається, використайте Start_HEX_compat.cmd.
Для діагностики: Start_HEX.cmd та HEX_import.log.
Не запускайте гру безпосередньо з вікна архіватора.

ВІЗУАЛЬНЕ ОНОВЛЕННЯ
Мальована 2D fantasy/storybook-графіка: контури тушшю, приглушені
акварельні кольори, вертикальні спрайти з видимими фасадами й стовбурами.
Оновлено 12 текстур поверхні, маску світіння й фон меню; додано 31 PNG
рослинності, гір, будівель, персонажів та матеріалів. Масштаб деталей ґрунту
переналаштовано для наближення. Об'єкти сортуються за глибиною.
Місто: 51 будівля, 28 NPC, додаткові насадження, дим і легкий рух рослин.
Бій: нові поверхні, перешкоди й спрайти учасників.
Рух персонажів використовує похитування спрайтів, а не покадрову анімацію ходи.

КЕРУВАННЯ
Карта: WASD/стрілки — камера; колесо або +/- — масштаб; G — створити героя;
P — пауза часу; C — хмари; Esc — меню.
Місто: WASD — рух; Shift — біг; E — взаємодія; Tab — сумка; M — план.
Додаткові підказки відображаються в самій грі.

ПЕРЕВІРКА
Сцени міста, бою й карти завантажені та відрендерені в Godot 4.5.1
(Linux, OpenGL Compatibility). Входи до всіх 51 будівель доступні для пошуку
шляху; перевірка ресурсів пройшла. Windows-рушій із вихідного архіву збережено,
але безпосередній запуск Windows EXE у цьому середовищі не перевірявся.
Знімки фактичних сцен — у Preview. Вихідні атласи — game/art/source_atlases.
Докладніше про графіку й зміни — ART_DIRECTION.md.
