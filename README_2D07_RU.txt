Amber Game — 2D 07 (2026-10-23)

Основа: Amber Game 2D Storybook. Запуск как раньше: Start_HEX.cmd (сначала импорт, потом игра).

Что нового по сравнению со Storybook:
1. Патч 01, перенесённый на Storybook: город внутри одной области, вход через ворота, имена НПС, прямые пути в бою, окна героя.
2. Радиальные города: круглая стена, площадь в центре, улицы лучами и кольцами. На общей карте видна миниатюра города.
3. Инвентарь «синий мрамор» и кукла героя. Надетая одежда видна на кукле, добавлено 8 вещей одежды.
4. Растущий город. Сначала в Чёрнославле только лачуга героя и общий дом, где живут глава Беорхтнот, травница Бригит и кожевник Эдрик.
   У каждого жителя есть поручения: пройти по округе, победить в бою, принести вещь или внести монеты.
   Сданные поручения выращивают город: Острог → Слобода → Посад → Город → Чёрнославль.
   На каждом этапе появляются новые дома и жители со своими поручениями. Этап и открытые поручения висят на доске объявлений.
5. Комикс-набор: текстуры земли, спрайты, здания и фон меню. Рамки интерфейса из набора не подключены, у инвентаря остался мрамор.
