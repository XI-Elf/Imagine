# Обзор региона — список картинок для генерации

Сгенерировано `game/tools/make_region_art.py`. Все картинки лежат в `game/art/region/` (заглушки). Чтобы заменить: сохраните PNG **с тем же именем**, тем же размером (или крупнее в тех же пропорциях) и положите в папку `region_art/` рядом с `AmberRegions.exe` (или `AmberWorld.exe`), либо в `game/art/region/` исходников. Код менять не нужно: игра сама берёт картинку из `region_art/`, если она есть. Террейны — в `region_art/terrain/`.

## Общий стиль (вставлять в начало каждого промпта)

Это копия стиля-якоря игры (`amber2d/style/prompt_style_25d.md`) — один стиль на все картинки.

```
Game asset in a unified 2.5D style, close to realism: physically based painted look, semi-realistic proportions, believable materials (worn leather, dull iron, rough wool, weathered wood, cracked stone, corroded alloy). Slightly top-down three-quarter view, camera about 35 to 40 degrees above the horizon, same angle for every asset, subject centered with a little margin. Soft directional light from the upper left, gentle ambient occlusion, subtle rim light. Dark sci-fi fantasy setting: medieval European world with remnants of lost technology. Muted desaturated palette (ash grey, mud brown, dark olive, rust, cold steel blue), small accents of amber glow only on technology and amber stones. Fine surface detail, scratches, dust, wear, no cartoon outlines, no cel shading, no pixel art, no glossy plastic, no neon, no text, no watermark, no logo.
```

Негативный промпт (если генератор его принимает):

```
cartoon, comic outline, cel shading, anime, pixel art, flat vector, oversaturated colors, neon, glossy plastic, text, letters, watermark, logo, frame, border, multiple objects, cropped subject, extreme perspective, fisheye, blur, low detail, modern clothing, guns, cars
```

Совет из файла стиля: первую удачную картинку подавайте дальше как референс стиля, один сид на всю серию.

**Точка опоры** — пиксель картинки, который ставится на точку земли (у объектов — низ по центру, где предмет касается земли). Тень игра рисует сама (свет слева сверху, тень вправо вниз), поэтому на картинке тени на землю быть не должно.

### Здания по этапам роста города (необязательно)

Для каждого здания с пометкой «этапы» можно дать свой вид на каждом этапе: `bld_<вид>_s0.png` … `bld_<вид>_s4.png` (0 Форт, 1 Деревня, 2 Бург, 3 Город, 4 Крупный город). Размер и опора — как у основного файла. Нет файла этапа — берётся основной.
