# Обзор региона и просмотрщик регионов

Режим «Обзор региона» — весь регион (область с цветной границей) на одном экране в виде **топографического листа**
(с 2026-11-06; раньше это была рисованная 2.5D-картинка с деревьями и горами-спрайтами). Палитра — как у утверждённой
топокарты мира (`art/map/map_topo.png`): кремовый берег, зелёная низина, охристо-коричневое нагорье, бордовые берега и
дороги, фиолетовый штрих проклятых земель, сине-серая вода.

Основа листа — **уже утверждённая топокарта мира** (`art/map/map_topo.png`, без запечённых подписей: `art/map/map_topo_clean.png`,
готовит `game/tools/make_topo_clean.py`): гипсометрия, светотень, берега, реки, дороги, штрих проклятых земель и жарких гор берутся
с неё. Новой карты не рисуется, её только улучшают данными игры (чёткие горизонтали, береговая линия, знаки, туман).
Данные «Местности» переносятся в топографическую модель, а не рисуются поверх:

| Данные игры | Что на листе |
|---|---|
| высоты (`map_height.png`, те же, что ведут героя в гору) | горизонтали (шаг 40/20/10 м по масштабу, каждая пятая жирнее и подписана), гипсометрия, светотень, высотные отметки на вершинах (высоты — над низиной) |
| вода (`map_water.png`) | берег, отмель, реки не тоньше ~2 px, волны на глубине |
| биомы (`map_biomes.png`) | условные знаки: лиственное/хвойное дерево, кочки болота, точки пустоши; фиолетовый штрих проклятых земель; красный штрих жарких гор |
| поселения (рост города по заданиям, `city_growth`, органичная основа `settlement_ground`) | как на настоящих картах — обобщённый знак застройки в реальных метрах: чёрные кварталы по плану текущего этапа, улицы, стена частоколом (точки) или камнем (линия), башни, ворота, огороды; дома следующего этапа — пунктиром. На общем плане, где реальный размер (~80 м) меньше ~20 px, знак только увеличивается вокруг той же точки; при приближении он становится настоящим |
| протоптанные тропы героя | тонкая бордовая линия |
| руины, техноостовы, сигнальные вышки | условные знаки (обысканные тускнеют) |
| туман войны | «белое пятно»: неисследованное не рисуется вообще (ни горизонталей, ни знаков), а не закрывается облаками |

Рамка листа, километровая сетка с подписями, масштабная линейка, легенда условных знаков (**L**). Сюжетные метки кампании
на обзоре не рисуются.

## Как открыть

- В игре: **V** на общей карте. Закрыть — **V** или **Esc**.
- Отдельно: просмотрщик регионов `AmberRegions.exe` (тот же код игры, стартовая сцена `region_viewer.tscn`).
  Из исходников: `godot --path game res://region_viewer.tscn` или `Start_Regions.cmd`.

Клавиши: колесо — масштаб к курсору; перетащить ЛКМ или стрелки — сдвиг; клик по соседнему (приглушённому)
региону — перейти туда; PgUp/PgDn — предыдущий/следующий регион; **L** — легенда. В просмотрщике ещё: **G** — город вырос
на одно задание, **Shift+G** — город снова в начале, **F** — туман войны, **[ ]** — скорость времени,
**P** — пауза, **Esc** — выход.

## Картинки (больше не используются)

Топографический лист не рисует спрайты: деревья, горы, дома и т. п. из `game/art/region/` и каталог для нейросети
([АССЕТЫ.md](АССЕТЫ.md), [assets.csv](assets.csv), [prompts.txt](prompts.txt)) относились к прежнему 2.5D-режиму и остаются
в репозитории как справка. Из `art/region/` читаются только плоские текстуры (табличка названия региона). Папка `region_art/`
рядом с exe для спрайтов больше ничего не меняет — стиль листа задаётся шейдером и палитрой в `game/world/region_topo.gd`.

## Файлы кода

- `game/world/region_view.gd` — сам обзор (модуль игры): поселения, тропы, знаки, подписи, легенда.
- `game/world/region_topo.gd` — топомодель: шейдер листа (горизонтали, вода, знаки биомов, белое пятно), расчёт высотных отметок и подписей.
- `game/world/region_art.gd` — плоские текстуры (табличка); спрайтовый атлас (`load_all(true)`) остался для совместимости.
- `game/region_viewer.gd`, `game/region_viewer.tscn` — просмотрщик регионов.
- `game/tests/region_view_checks.gd` — проверки; `game/qa/region_shots.gd`, `game/qa/topo_shots.gd` — снимки и замеры.
