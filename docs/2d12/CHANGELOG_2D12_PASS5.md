# Amber World 2D 12 — Pass 5: основная сюжетная кампания

## Добавлено
- Новая data-driven система основной кампании `game/world/quest_campaign.gd`.
- Пять последовательных глав: сигнал из Эшвика, доверие жителей, янтарный след, опасность на дороге, поиск источника эха.
- Кампания получает события от существующих игровых систем: вход в Эшвик (`s001`), сдача обычных городских поручений, запись услышанной истории в кодекс, победы в боях и пройденное расстояние.
- Вкладка «Задания» показывает текущую главу, повествовательный текст и индикатор выполнения; личный журнал игрока и городские поручения сохранены.
- За завершение глав начисляется небольшая денежная награда.
- Состояние кампании сериализуется в `Worlds.to_dict()` и загружается из `Worlds.load_dict()`. Старые сохранения без ключа `campaign` получают чистое состояние; формат и версия старых сохранений не меняются.
- Добавлен `game/tests/quest_campaign_checks.gd` для проверки последовательности глав и наград.

## Ограничения проверки
- JSON и структура исходников проверяются статически.
- Godot 4.7 недоступен в среде сборки: тестовый скрипт и GDScript-парсер не запускались. Перед релизом требуется открыть проект в Godot 4.7 и выполнить тест `quest_campaign_checks.gd`.

## Важное
Кампания является первым играбельным каркасом истории, а не финальным сценарием. Ветвящиеся моральные решения, уникальные сцены, диалоги с постановкой, новые локации и последствия для мира — следующий этап наполнения.
