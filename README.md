# Amber Game (Amber World 2D)

Исходники 2D-ветки игры «Amber Game» на Godot 4 (папка `game/`, открывать `game/project.godot`).

- Первый коммит — исходники сборки **2D 07** как есть.
- Второй коммит — единое наложение `merged` поверх 2D 07 (все ветки фич: бесконечные квесты, ремесло, лошадь и повозка, гибель героя, интерфейс-комикс, звуки CC0, погода и др.) с удалением устаревших файлов. Это база будущей сборки 2D 08.

Не входит в репозиторий: бинарный редактор `_runtime/`, `AmberWorld.exe`, готовые zip-сборки и кэш `.godot/`.
Перед запуском или экспортом выполнить `godot --headless --path game --import`.
Скрипты `Start_HEX*.cmd/.vbs` ждут редактор в `_runtime/` и без него не работают.

Графика (Storybook, комикс) создана генератором изображений по заданию автора, см. `ART_DIRECTION.md`.
Звуки — CC0 1.0, автор и источник каждого файла в `game/audio/ЗВУКИ_CC0.txt`.
